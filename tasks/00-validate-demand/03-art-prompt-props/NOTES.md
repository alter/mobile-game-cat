# Why a 3-prop pilot before the full 30

Don't start with all 30 props. Start with a one-day pilot that answers "can
this be made at all" - see art-brief.md section 11.

The pilot is three tasks: this one (3 props), then one cat in two states
(04), then one room dirty/clean (05). Order matters: props are the cheapest
possible check that the prompt recipe and pipeline hold together, before
spending pilot effort on the two harder, riskier pieces (cat, room) that the
M0 creatives actually depend on.

Whatever appears in the M0 creatives must come from the same pipeline that
will make the real game - same prompt template, same style, no
hand-finishing. A creative that promises art the game cannot deliver makes
the cost-per-install measurement meaningless: it would measure demand for a
game that cannot be built.
