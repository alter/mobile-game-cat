# "Store placeholder page" is not an Apple-supported mechanism

Apple does not allow a listing - real or pre-order - to go live without a
build that has already passed review. What the industry calls a "fake door
store page" is one of two things: (a) an App Store pre-order page backed by a
minimal build that passed review, or (b) a separate web page imitating the
app card, measuring clicks on "Install" as a proxy for conversion.

Neither Custom Product Pages nor Product Page Optimization (App Store
Connect's tools for comparing creatives against each other) apply here - both
require an app already published in the store.

No reliable published data was found on how well the web-page proxy's
click-through predicts real-world CPI once the app is live. Treat it as an
industry-common practice, not a measured one.
