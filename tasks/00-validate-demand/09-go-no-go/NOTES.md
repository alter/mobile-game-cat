# The CPI < $5 gate is looser than it sounds

For context: median CPI across casual games on iOS was $1.41 (Liftoff/
Singular, 2025 Casual Gaming Apps Report, Feb 2024-Feb 2025); Adjust's 2025
report puts the median across all games at $0.36, and $1.22 in North
America. Those are live games with tuned campaigns, so not a like-for-like
comparison with a placeholder page - but a bar set at $5 is unlikely to
reject anything, which makes it a weak gate.

If the point of this decision is to filter, consider $2-3 instead. If the
point is only to catch a catastrophe, leave it at $5 and say so explicitly
in the written decision - don't let the number stay ambiguous about which
job it's doing.
