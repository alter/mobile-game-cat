GOAL
  Три дыры в сохранениях, каждая теряет файл или пускает мусор: копия вместо
  перемещения, формат полки без разделителя, roomsdone без проверки.

CONTEXT

  CatSaveFile.cs), Core/GameSave.cs (:43-44 полка+cap одной строкой, :90-91

  Аудит 2026-09-01, разбор Core, пп. 2.6, 2.9 (Shell) и дыры покрытия 2, 4.

SCOPE
  + File.Replace (или Move с заменой) вместо WriteAllText+Copy+Delete.
  + Формат полки получает разделитель или экранирование; старые файлы
    читаются по-прежнему (запасная ветка чтения).
  + roomsdone проверяется как cursorRoom: комнаты существуют, повторов нет.
  + Круговой тест на настоящем файле уровня (имена prop_*), не на «a b c».
  - Версию формата не поднимать без необходимости: цель — прочность, не смена.
