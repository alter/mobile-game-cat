TASK: Cat layer masks - only the ones worth drawing

GOAL
  Replace computed coat masks with hand-drawn ones where, and only where, the
  computed mask reads wrong. The shader no longer waits on this: since
  60-shell-build/18 every mask is derived from the silhouette at runtime, so
  this task is polish, not a blocker. See NOTES.md.

CONTEXT
  game/Assets/View/CoatMasks.cs (how each mask is computed today)
  game/Assets/View/CoatBuilder.cs, MaskOf (how a drawn file overrides one)
  tasks/60-shell-build/18-coat-shader/NOTES.md (which computed masks are weak)
  art-brief.md section 7, "Mask requirements"
  40-art/03-cat-silhouettes/NOTES.md (why not generated by a model)

SCOPE
  + Tabby stripes first, and possibly only. Computed stripes run down the
    frame, not around the animal: on the sleeping state they cross a curled
    body the wrong way. This is the one mask that reads as wrong rather than
    merely plain. Three files (one per state, short fur), six with long fur.
  + Any other mask ONLY after it has been looked at on a device and found
    wrong. Judge from the pattern grid (drop a `coat.txt` beside the save),
    not from this task's list.
  + Hand-traced against the accepted base, pixel-for-pixel, same pose/frame.
  + White markings readable by outline+shadow on white fur, not fill alone.
  - NOT 54 files, and not 9 per silhouette. That was the scope while the
    shader had no masks at all. Drawing a mask the code already computes
    acceptably buys nothing and costs a day each.
  - Not the base silhouettes - see 40-art/03-cat-silhouettes, accepted first.
  - Not the runtime shader - built, 60-shell-build/18.
  - No AI-generated mask. Unchanged, and for the unchanged reason: a model
    asked for "the same cat but striped" draws a different cat. Note that
    computing a mask FROM the base is neither generation nor tracing - the
    base is the input, so alignment is exact by construction, which is the
    property the ban was protecting.

OUTCOME
  Zero or more mask PNGs named cat_<state>_<fur>_pattern_<name>.png /
  _mark_<name>.png / _eyes.png, 1024x1024, strict black/white with <=2px edge
  antialiasing, under game/Assets/Art. CoatBuilder picks each one up with no
  code change. Zero is a legitimate outcome: it means the computed masks were
  judged good enough, and that judgement, written down, is the deliverable.

VERIFY (QA)
  1. Every drawn mask pure black/white and does not extend past the base's
     alpha.
  2. Overlaying each drawn mask on its base at 100% opacity: zero pixel
     offset.
  3. The pattern grid photographed before and after, side by side, checked by
     someone other than the mask author: the drawn mask is visibly better, or
     it does not ship.
  4. A written line per mask NOT drawn, saying it was looked at and judged
     good enough. This is the deliverable when nothing is drawn.

ROLE
  ART, QA

DEPENDS
  40-art/03-cat-silhouettes
